## 1. 产品简介

**RuiJie-DiiS** 是一款面向企业数据分析场景的 AI 数据智能工作台。你可以通过自然语言向系统提问，系统自动连接数据源、检查数据 schema、执行只读 SQL、生成分析结论，并把每一步操作完整记录下来。

### 1.1 你能用 RuiJie-DiiS 做什么

| 场景 | 示例问题 |
|------|---------|
| 探表 | "这个数据源里有哪些表？每张表主要字段是什么？" |
| 指标统计 | "按渠道统计订单量和 GMV。" |
| 趋势分析 | "分析最近 30 天 GMV 趋势，找出波动最大的日期。" |
| 多轮追问 | "再按品类拆分一下。" |
| 跨表分析 | "对比各渠道的 GMV、毛利、投放和退款。" |

### 1.2 核心特点

- **自然语言提问**：用中文或英文直接描述分析需求。
- **多数据源支持**：PostgreSQL、MySQL、ClickHouse、DuckDB、SQLite、CSV、Excel、MongoDB、Redis、Elasticsearch 等。
- **只读安全执行**：系统默认不会修改你的生产数据。
- **全程可追溯**：每一次分析都有完整记录，包括用了哪些表、执行了什么 SQL、得出了什么结论。
- **中英双语界面**：默认中文，可切换英文。

## 2. 登录与账户

### 2.1 打开系统

在浏览器中访问管理员提供的 Web 地址，例如：

```text
http://localhost:3000/login
```

你会看到登录页面，默认显示中文：

- 标题：登录
- 副标题：欢迎回到 RuiJie-DiiS
- 邮箱、密码输入框
- 登录按钮
- 忘记密码链接
- 创建账户入口

### 2.2 注册账户

如果你是第一次使用：

1. 点击「初次使用 RuiJie-DiiS？创建账户」。
2. 填写邮箱、显示名称、密码（至少 6 位）。
3. 点击「创建账户」。
4. 根据系统配置，你可能需要：
   - 查收邮箱验证邮件并点击链接，或
   - 将管理员/控制台提供的验证码填入验证页面。
5. 验证完成后返回登录页，输入邮箱和密码登录。

> 注意：如果管理员关闭了自助注册，你需要联系管理员为你创建账户。

### 2.3 忘记密码

1. 在登录页点击「忘记密码？」。
2. 输入你的注册邮箱。
3. 系统会发送重置链接或重置码。
4. 按提示设置新密码后重新登录。

### 2.4 退出登录

点击左侧用户菜单 →「退出登录」。

## 3. 界面总览

登录后进入 `/data-tasks` 工作台，界面分为三个主要区域：

| 区域 | 位置 | 用途 |
|------|------|------|
| 左侧边栏 | 最左 | 管理数据任务会话、工作区资源、用户菜单 |
| 中间对话区 | 中央 | 输入问题、查看 Agent 回复和运行过程 |
| 右侧控制台 | 最右 | 查看概览、追溯、产出、步骤详情、工作区文件 |

窗口较小时，右侧控制台会自动收起为抽屉。你可以点击聊天区顶部的「控制台」按钮重新打开。

### 3.1 左侧边栏

#### 会话列表

- **新建数据任务**：开始一个新的分析会话。
- **搜索会话**：按名称查找历史会话。
- **会话操作**：将鼠标悬停在会话上，可重命名、置顶、删除。

#### 工作区资源

- **数据源**：查看、添加、测试已连接的数据库或文件。
- **知识库**：管理文档和问答知识。
- **Agent 工具**：配置 MCP Server、Skill 等扩展工具。
- **模型**：配置和测试大语言模型（LLM）。
- **资源文件**：查看已上传到工作区的文件。

#### 用户菜单

- 显示当前登录用户。
- 设置（语言切换、账户相关）。
- 退出登录。

### 3.2 中间对话区

这是你与数据分析 Agent 交互的主要区域。你会看到：

- 你发送的问题。
- Agent 的流式回复。
- 分析过程中的步骤卡片，例如：
  - 检查数据源 schema
  - 执行 SQL 查询
  - 读取文件
  - 生成表格或图表
- 等待你确认或补充信息的交互提示。

### 3.3 右侧控制台

控制台包含多个标签页：

| 标签 | 用途 |
|------|------|
| 概览 | 当前问题、步骤数量、运行状态、Token 用量 |
| 追溯 | 按时间排列的执行记录，以及语义 DAG 图 |
| 产出 | Agent 生成的表格、图表、SQL、报告、文件 |
| 详情 | 单个步骤的输入、输出、工具调用参数 |
| 工作区文件 | 当前可复用的上传文件和文件型产出 |

## 4. 创建并运行第一个数据任务

### 4.1 开始新任务

1. 点击左侧「新建数据任务」。
2. 在中间输入框下方，确认已启用至少一个数据源。
   - 首次体验推荐使用内置的 **DTC Growth Review** 数据源。
3. 在输入框旁选择要使用的模型。
   - 如果没有模型可选，请先进入「工作区资源 → 模型」创建并启用一个 LLM Profile。

### 4.2 输入你的第一个问题

在输入框中输入：

```text
帮我查看数据源里有哪些表，并说明每张表的主要字段。
```

按 Enter 或点击发送按钮。

### 4.3 观察分析过程

Agent 会依次执行：

1. **检查 schema**：查看数据源中有哪些表和字段。
2. **生成 SQL**：根据你的问题生成只读查询。
3. **执行查询**：在只读边界内运行 SQL。
4. **整理结论**：用自然语言回答你的问题。

你可以在中间区域看到步骤卡片，在右侧控制台查看更详细的执行信息。

### 4.4 继续追问

你可以继续输入：

```text
按渠道统计订单量和 GMV。
```

或：

```text
再按品类拆分一下。
```

系统会基于当前会话上下文继续分析。

### 4.5 停止运行

如果 Agent 运行时间过长或问题有误，点击输入框附近的「停止」按钮。已产生的中间结果仍可查看。

## 5. 工作区资源

### 5.1 数据源

数据源是 RuiJie-DiiS 分析的基础。你可以在「工作区资源 → 数据源」中：

- 查看已有数据源。
- 点击「新增数据源」添加新的数据库或文件。
- 测试连接是否正常。
- 抓取 schema，让 Agent 知道有哪些表和字段。
- 浏览表结构和表数据预览。

#### 安全提示

- 建议使用只读账号连接生产数据库。
- 连接凭据不会回显到前端，也不会进入 Agent 的上下文。
- 管理员可以设置查询行数限制、超时时间和敏感字段脱敏。

### 5.2 模型

模型决定了 Agent 使用哪个大语言模型进行理解和推理。

1. 进入「工作区资源 → 模型」。
2. 点击「新增模型」或编辑已有模型。
3. 填写：
   - 名称
   - 模型类型（通常为 openai-compatible）
   - 模型 ID（例如 `qwen-plus`、`deepseek-chat`）
   - Base URL
   - API Key
4. 点击「测试」确认连接成功。
5. 启用该模型。

### 5.3 知识库

知识库用于上传和管理业务文档，例如指标定义、业务口径说明等。Agent 在分析时可以检索相关知识，提高结论准确性。

### 5.4 Agent 工具

这里可以配置：

- **MCP Server**：外部工具服务，例如 Data Link 语义图服务。
- **Skill**：预定义的 Agent 技能包。

普通用户通常由管理员预配置，直接使用即可。

## 6. 会话管理与分支

### 6.1 切换会话

左侧会话列表显示你的所有历史会话。点击即可切换。

### 6.2 重命名会话

将鼠标悬停在会话名称上，点击编辑按钮，输入新名称后确认。

### 6.3 置顶会话

点击会话旁的置顶图标，常用会话会固定在列表顶部。

### 6.4 删除会话

点击会话旁的删除图标。删除后不可恢复，会话中的对话、运行记录和产出将被清除。

### 6.5 恢复会话

刷新页面或重新登录后，你可以从左侧列表恢复之前的会话。恢复后：

- 中间显示完整对话历史。
- 右侧控制台可查看之前的运行记录和产出。
- 新问题会沿用该会话的上下文。

### 6.6 创建分支

如果你想基于历史某个问题进行新的探索，可以：

1. 在历史轮次旁点击「重问」或编辑该问题。
2. 系统会创建一个新的子分支会话。
3. 原会话历史保持不变，你可以在新分支中继续分析。

这适用于对比不同分析路径、假设验证等场景。

## 7. 查看结果与产出

### 7.1 产出类型

Agent 完成分析后，会在右侧「产出」面板生成以下类型的结果：

| 类型 | 说明 | 操作 |
|------|------|------|
| 表格 | 查询返回的数据表 | 预览、搜索、排序、下载 CSV/XLSX |
| 图表 | 可视化图形 | 预览、下载 |
| SQL | Agent 执行的查询语句 | 查看、复制 |
| 报告 | 结构化分析结论 | 查看 Markdown 内容 |
| 文件 | 生成的文件 | 下载或加入工作区 |

### 7.2 下载数据

- 表格：点击表格产出，选择「下载 CSV」或「下载 XLSX」。
- 图表：点击图表产出，选择下载格式。
- 文件：点击文件产出，选择「下载」。

### 7.3 将产出加入工作区

对于文件型产出，你可以点击「加入工作区」。加入后：

- 文件会出现在右侧「工作区文件」面板。
- 你可以在后续会话中通过 `@文件名` 引用它。

### 7.4 引用产出到下一轮

1. 在「产出」面板中打开某个表格或报告。
2. 选择你想引用的区域（如某几行数据、某段文字）。
3. 点击「引用到输入区」。
4. 输入新的问题并发送。

这可以让 Agent 基于已有结论做进一步分析。

## 8. 数据安全与审计

### 8.1 只读执行

RuiJie-DiiS 默认对数据库执行只读查询，Agent 不会执行 INSERT、UPDATE、DELETE、DROP 等修改操作。

### 8.2 凭据保护

- 数据库密码等凭据只在创建或更新数据源时提交。
- 前端和管理界面不会回显明文密码。
- 凭据不会进入 Agent 的推理上下文。

### 8.3 查询边界

管理员可以配置：

- 最大返回行数
- SQL 执行超时时间
- 敏感字段脱敏
- 允许/禁止访问的表

### 8.4 全程审计

每次分析都会记录：

- 使用了哪个数据源
- 检查了哪些 schema
- 执行了哪些 SQL
- 产生了哪些产出
- Token 用量

你可以在右侧「追溯」面板中查看完整记录。

## 9. 常见问题

### Q1：登录页面显示英文，怎么切换中文？

系统默认中文。如果显示英文，点击页面上的语言切换按钮（中/EN）即可。

### Q2：提示"请先在配置面板中启用 LLM"怎么办？

你需要先配置并启用一个模型：

1. 进入「工作区资源 → 模型」。
2. 新增或编辑模型，填写 API Key 和 Base URL。
3. 点击「测试」确认连接成功。
4. 启用该模型。

### Q3：为什么 Agent 说找不到表？

可能原因：

- 数据源未启用：在输入框底部检查该数据源是否已勾选。
- Schema 未抓取：进入「数据源」页面，对该数据源执行「抓取 schema」。
- 账号权限不足：确认连接账号有读取相关表的权限。

### Q4：分析结果看起来不对怎么办？

1. 查看右侧「追溯」面板，确认 Agent 使用了哪些表和 SQL。
2. 点击具体步骤查看详情，检查 SQL 是否符合预期。
3. 用更明确的提问补充业务背景，例如：
   - "GMV 指订单金额，不要包含退款。"
   - "渠道字段用 channel_name，不要 channel_id。"

### Q5：可以上传自己的数据文件吗？

可以。在输入框中点击上传按钮，或在「工作区资源 → 资源文件」中上传。支持的格式包括 CSV、Excel 等。上传后可以在分析中引用。

### Q6：会话会保存多久？

会话数据保存在服务端。只要服务端存储不被清理，你可以随时恢复历史会话。具体保留策略由管理员决定。

### Q7：可以同时打开多个数据任务吗？

可以。左侧会话列表中可以切换不同任务，多个会话独立运行。

### Q8：如何查看某个步骤的详细执行信息？

1. 在中间对话区点击该步骤卡片。
2. 或在右侧「追溯」面板中找到该步骤并点击。
3. 右侧会切换到「详情」标签，显示输入、输出、工具调用参数等。

### Q9：为什么页面显示"品牌"还是旧名称？

如果你看到旧的品牌名称，可能是浏览器缓存。请尝试：

1. 按 `Ctrl + Shift + R` 强制刷新。
2. 或清除浏览器缓存后重新访问。
